# Futian post — syndication copy

The same post as `src/content/posts/futian-new-downtown.ts`, as plain Markdown for
pasting into an external blog platform (Medium, Substack, note, Blogger, LinkedIn
articles). Images are in `images/`, exported as JPEG from the site's WebP files.

How to post it:

1. Paste `futian-new-downtown.md` into the platform's editor (Medium: Import a story
   does not accept local files, so paste; Substack and note accept Markdown paste).
2. Upload the four images from `images/` where the `![...]` lines are. The alt text
   is in the brackets; the italic line under each image is the caption.
3. **Set the canonical URL** to `https://www.shenzhen-buddies.com/blog/futian-new-downtown`
   so search engines credit the site, not the platform. Medium: story settings →
   "Advanced settings" → canonical link. Substack and note have no canonical field,
   so the "Originally published at" line at the end has to do that job.
4. Links in the copy carry `utm_source=syndication&utm_medium=blog&utm_campaign=futian-new-downtown`.
   Change `utm_source` to the platform name (`medium`, `substack`, `note`) before posting
   so the traffic is attributable per platform.
5. The light-show paragraph and FAQ answer are dated "as of October 2026". When the
   schedule changes, update the site post first, then edit the syndicated copy.

Translations (Japanese, Simplified and Traditional Chinese) live on the site at
`/ja/blog/…`, `/zh-Hans/blog/…` and `/zh-Hant/blog/…`; export those the same way if a
non-English platform (note is Japanese-first) is the target.
